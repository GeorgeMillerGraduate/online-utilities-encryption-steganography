Crypto Studio.

Encrypt a message. Hide it in a PNG. Recover it later.

Processed in your browser. No account required.

How it works

A password derives an AES-GCM key using PBKDF2. The encrypted message can be copied as text or stored in a PNG’s pixel bits.

You need the same password to recover it. A wrong password or changed message fails authentication.

Save the original PNG. Resizing, editing or JPEG conversion can destroy its hidden data.
